## Your link

Under **Account › Refer and earn** you have a personal code and link (`/r/<code>`). Share it with a
school, college or any organization.

- **Registered through it:** whoever follows your link and registers an organization from that
  browser within 30 days brings it to you. Its owner can also type your code when paying for a
  plan, if it wasn't registered through a link.
- **What you earn:** a share (5% by default) of each payment the organization makes, before GST,
  for its first months (3 by default) counted from its first payment.
- **Never your own:** an organization you create, or one you're already a member of, doesn't count.
- **On the page:** the organizations you referred and where each is (waiting for approval, active,
  paying), and each earning: owed or paid.

## Creator links and campaign coupons

Under **Dashboard › Referrals › Links and coupons** (the platform owner):

- **A creator link** belongs to a sponsored creator (they need an account): it earns them a share,
  which can differ from the usual one, and may also give the organizations it brings a discount.
- **A campaign coupon** gives a discount and earns nobody. Organizations type it when paying.
- Each can have dates, a limit on how many organizations use it, a note, and be paused. A coupon
  that's paused, not started, expired or used up is refused at checkout, saying why.

A code's discount applies to payments in the same window, comes off before GST, and shows as its
own line on the invoice. Prices are always worked out on the server.

### Who a code is for, and codes that combine

Each code can also say:

- **Who can use it at checkout:** new organizations (never paid), existing ones (paid, plan
  active) and inactive ones (paid before, plan now past due or paused), in any mix. None ticked
  means everyone. A code typed by an organization it isn't for is refused, saying who it's for
  ("This code is for new organizations.").
- **Combine with a referral discount:** an organization that came through a referral link gets
  that link's discount automatically. With this on, a promo code adds its discount on top (never
  past the price). With it off, the promo code replaces the referral discount for that payment.
  A typed code that gives no discount of its own never takes the referral discount away.

### Applying a code

On **Manage › Plan and billing**, type the code and press **Apply**. The page shows each discount,
and what's left to pay with GST, before anything is charged, or why the code can't be used. One
code at a time: an applied code shows with **Remove**, and the box comes back only once it's
removed. The total follows any change to the plan. Applying makes no order and doesn't tie the
organization to the code; paying does. An organization can try 60 codes an hour.

## Paying out

Earnings are tracked, not paid automatically. **Dashboard › Referrals › Earnings** lists what's
owed first; pay referrers by UPI or bank, tick what you paid, add a note (the UPI reference), and
**Mark paid**. Marking paid or cancelled asks you to confirm it's you, and is in the activity log.
**Rules** sets the share, the months and whether refer and earn is on (off: no new referrals,
discounts or earnings; what's owed stays owed).
